## hDashboard - Main Dashboard

### Overview
The main dashboard serves as the central hub for household users, providing quick access to all key features and displaying important statistics.

### Key Features

#### 1. Welcome Header
- **Personalized Greeting**: Displays "Hi, [Username]!" with user's name
- **Help Button**: Tap the "?" icon to restart the tutorial guide anytime
- **Notifications Bell**: Shows unread notification count with red badge

#### 2. Banner Section
- **Environmental Message**: "Practice Food Waste Segregation"
- **Visual Elements**: Features trash can icon and gradient background
- **Mission Statement**: "Let our household be the sprout of change in our environment"

#### 3. Map Access Card
- **Quick Navigation**: "View the waste containers near you" button
- **Direct Access**: Takes you to hMap page for container locations

#### 4. Statistics Cards

##### Total Contribution Card
- **Display**: Shows total kilograms of food waste donated
- **Icon**: Green contributions icon
- **Real-time Updates**: Refreshes when new donations are made

##### Reward Points Card
- **Display**: Shows current reward points balance
- **Icon**: SIBOL points icon
- **Currency**: Used for redeeming rewards in hRewards

#### 5. Leaderboard Section
- **Community Ranking**: Shows top contributors in Barangay 176-E
- **User Position**: Displays your current ranking
- **Motivation**: Encourages friendly competition among users

#### 6. QR Scanner Access
- **Bottom Navigation**: Scan button in bottom nav bar
- **Camera Integration**: Opens camera for QR code scanning
- **Point Awards**: Earn points for scanning valid waste QR codes

### How to Use

1. **View Statistics**: Your contribution and points are displayed prominently
2. **Access Map**: Tap "View Map" to find nearby waste containers
3. **Scan QR**: Use bottom nav scan button to scan waste QR codes
4. **Check Rankings**: View leaderboard to see community standings
5. **Get Help**: Tap "?" button anytime for tutorial guidance

### Interactive Tutorial Zones
- **Zone 1**: Help button - Restart tutorial guide
- **Zone 2**: Notifications bell - View important updates
- **Zone 3**: Map card - Access waste container locations
- **Zone 4**: Total contribution - View waste donation statistics
- **Zone 5**: Reward points - Check available points balance
- **Zone 6**: Leaderboard - View community rankings

## hRewards - Rewards Redemption

### Overview
Redeem your hard-earned reward points for exciting items and privileges through the comprehensive rewards catalog.

### Key Features

#### 1. Points Balance Display
- **Current Points**: Shows available points for redemption
- **Real-time Updates**: Balance updates after each redemption
- **Visual Indicator**: Clear display of points available
- **Gift Icon**: Visual representation of rewards system

#### 2. Rewards Catalog
- **Grid Layout**: Visual display of available rewards
- **Reward Images**: Visual preview of each item
- **Point Requirements**: Clear display of points needed
- **Availability Status**: Shows if reward is claimable

#### 3. Redemption Process
- **One-tap Claiming**: Simple redemption process
- **Code Generation**: Unique redemption codes for each claim
- **Instant Confirmation**: Immediate feedback on successful claims
- **Point Deduction**: Automatic point balance update

#### 4. Claim Management
- **Claim Codes**: Unique codes for reward collection
- **Download Option**: Save or share claim codes
- **Reward Details**: Information about claimed items
- **Collection Instructions**: How to redeem physical rewards

### How to Use

1. **Check Points**: View your available points balance at top
2. **Browse Rewards**: Scroll through available rewards catalog
3. **Check Eligibility**: Verify you have enough points for desired reward
4. **Claim Reward**: Tap "Claim Now" on eligible rewards
5. **Get Code**: Receive unique redemption code
6. **Save/Share**: Download or share your redemption code
7. **Collect Reward**: Present code to barangay staff for reward collection

### Reward Categories

#### Available Rewards
- **Household Items**: Useful items for home use
- **Food Items**: Grocery items and food products
- **Services**: Community services and privileges
- **Gift Certificates**: Vouchers for local establishments

#### Point System
- **Earning Points**: Accumulated through QR scans and contributions
- **Tier System**: Different point requirements for different reward tiers
- **Balance Tracking**: Real-time point balance updates
- **Transaction History**: Complete record of point transactions

### Redemption Process

#### Before Claiming
- **Check Balance**: Ensure sufficient points available
- **Review Reward**: Confirm reward details and requirements
- **Plan Collection**: Consider when and how to collect reward

#### Claiming Process
1. **Select Reward**: Choose desired reward from catalog
2. **Verify Points**: Confirm sufficient point balance
3. **Confirm Claim**: Tap "Claim Now" to proceed
4. **Receive Code**: Get unique redemption code
5. **Save Code**: Download or screenshot the code
6. **Collect Reward**: Present code at designated collection point

#### After Claiming
- **Code Management**: Keep redemption code safe
- **Collection Timeline**: Follow collection instructions
- **Point Updates**: Verify point deduction in balance
- **Reward History**: Track claimed rewards in history

## Troubleshooting Common Issues

### QR Scanner Problems
- **Permission Denied**: Enable camera permissions in device settings
- **Blurry Images**: Ensure good lighting and steady hand
- **Invalid Codes**: Verify QR codes are from authorized sources
- **Scan Failures**: Retry scanning or check network connection

### Map Issues
- **Location Not Found**: Enable GPS/location services
- **Inaccurate Position**: Wait for GPS to stabilize
- **Container Not Showing**: Check network connection and refresh
- **Route Problems**: Ensure location services are working properly

### Profile Updates
- **Save Failures**: Check network connection and retry
- **Image Upload Issues**: Verify image format and size requirements
- **Username Conflicts**: Choose a unique username
- **Password Problems**: Follow password requirements carefully

### Reward Redemption
- **Insufficient Points**: Earn more points through QR scanning
- **Claim Failures**: Check network connection and retry
- **Code Issues**: Save redemption codes immediately
- **Collection Problems**: Contact barangay staff for assistance

### Notification Problems
- **Missing Updates**: Check app notification permissions
- **Delayed Alerts**: Ensure stable internet connection
- **Read Status Issues**: Refresh the page to update status
- **Filter Problems**: Verify date range selections
